갈색 강아지 한 마리로 8개 행동을 모두 확인할 수 있게 묶었어. 25일에 확인한 기본 캐릭터와 수정된 걷기·달리기를 그대로 사용했어. 냄새 맡기, 꼬리 흔들기, 눕기는 같은 기본 이미지로 PixelLab에서 추가 생성했어.

먼저 ZIP을 풀고 `index.html`을 브라우저로 열면 돼. 인터넷이나 API 키 없이 실행돼. 행동별로 멈추고 프레임을 넘겨 볼 수 있고, 이동 켜기와 속도 조절로 맵에서 쓸 값을 맞출 수 있어.

## 파일 안내

| 파일 | 용도 |
| --- | --- |
| `sheets/*.png` | 앱에 넣을 8개 투명 배경 가로 스프라이트 시트 |
| `frames/행동/00.png…` | 시트 재생이 어려울 때 쓸 낱장 200장, 0부터 시작 |
| `base.png` | 기본 이미지, 행동으로 선택하는 항목은 아님 |
| `manifest.json` | 프레임 좌표·시간, 반복·유지·복귀 정보, 이동 기본값 |
| `playback.ts` | 프레임 선택, 역순 복귀, 이동·기준점 계산 함수 |
| `index.html` | 오프라인에서 실행되는 8개 행동 미리보기 |
| `previews/*.gif` | 행동별 공유용 미리보기 |
| `contact-sheets/*.png` | 전체 프레임을 펼쳐 놓은 확인용 이미지 |
| `overview.gif`, `overview.png` | 8종을 한눈에 보는 미리보기 |

GIF는 브라우저가 짧은 프레임 시간을 반올림할 수 있어. 실제 재생 시간은 manifest와 HTML을 기준으로 봐줘.

## 8개 행동 값

모든 프레임은 64×64px, 공통 발 기준점은 **(32, 60)**. 시트는 가로 한 줄이야.

| 코드 | 행동 | 장수 | 한 장 / 한 주기 | 맵 속도 기본값 | 종료 |
| --- | --- | ---: | --- | --- | --- |
| IDLE | 가만히 살펴보기 | 16 | 140ms / 2.24초 | 0 | 반복 |
| WALK | 천천히 걷기 | 48 | 30ms / 1.44초 | 0.8타일/초 전진 | 반복 |
| RUN | 신나게 달리기 | 48 | 15ms / 0.72초 | 1.8타일/초 전진 | 반복 |
| SNIFF | 냄새 맡기 | 16 | 100ms / 1.60초 | 0 | 반복 |
| TAIL_WAG | 꼬리 흔들기 | 16 | 90ms / 1.44초 | 0 | 반복 |
| BACK_OFF | 한 발 물러나기 | 24 | 70ms / 1.68초 | 0.6타일/초 후진 | 반복 |
| SIT | 잠깐 앉기 | 16 | 90ms / 1.44초 | 0 | 마지막 자세 유지 → 역순 복귀 |
| LIE_DOWN | 편안히 쉬기 | 16 | 100ms / 1.60초 | 0 | 마지막 자세 유지 → 역순 복귀 |

앉기·눕기는 들어가는 동작을 한 번 재생하고 마지막 장에서 멈춰. 일어날 때 역순으로 돌아온 다음 이동을 시작하면 돼. 미리보기는 확인하기 편하게 1.2초 유지 후 자동으로 일어나지만, 앱에서는 행동 설정의 유지 시간을 사용해줘.

## x값은 세 가지를 구분하면 돼

1. **시트 안의 x**: 0번은 0, 1번은 64, 2번은 128… `manifest.animations[code].frames[index].x`를 읽어 잘라내는 값이야. 맵 위치와는 무관해.
2. **그림을 붙이는 위치**: 맵에서 강아지 발 좌표가 `(worldX, worldY)`라면, 그림 왼쪽 위는 `(worldX - 32×배율, worldY - 60×배율)`이야. 행동마다 기준점을 바꾸지 않아.
3. **맵에서 움직이는 거리**: `정규화한 방향 × 속도(타일/초) × 경과 초`. 픽셀로 계산한다면 여기에 맵의 한 타일 크기를 곱해줘. BACK_OFF만 방향에 -1을 곱하고, 강아지가 바라보는 방향은 유지해.

예를 들어 한 타일이 32px라면 걷기는 25.6px/초, 달리기는 57.6px/초, 후진은 19.2px/초야. 이미지 한 프레임이 넘어갈 때마다 x를 일정하게 더하면 기기 성능에 따라 속도가 달라지니 경과 시간으로 계산해줘. 카메라 확대와 캐릭터 이미지 배율은 별도야.

기본 속도는 시작점이야. 실제 연결에서는 `/v1/dogs/{dogId}/behavior`의 `settings.actions[code].speedTilesPerSecond`를 우선해서 읽으면 돼. 충돌 범위는 맵에 맞춰 정하고, 프레임마다 달라지는 몸통 경계 대신 발 주변의 고정 범위를 써줘.

## 서버 연결할 때

- 이 ZIP은 모든 코드를 구현해보는 **8종 기준 묶음**이야. 실제 강아지는 공통 IDLE/WALK/SIT와 특징 행동을 합쳐 보통 3~5종이 와.
- `/v1/dogs/{dogId}/assets`의 `availableActions`에 있고, 행동 설정의 `weight > 0`인 항목만 후보로 쓰면 돼. 로딩·상황·cooldown 조건도 확인해줘.
- ZIP의 경로는 상대 파일 경로야. 실제 서버 응답에서는 `spritesheetUrl`을 읽고, 만료되면 에셋 API를 다시 조회해줘. ZIP에 개발 서버의 인증·만료 URL은 들어 있지 않아.
- 프레임 수를 16장으로 고정하지 말고 받은 `frames`를 사용해줘. WALK/RUN은 48장, BACK_OFF는 24장이야.
- 제공 방향은 오른쪽 3/4뷰 한 방향이야. 왼쪽은 좌우 반전으로 시연할 수 있지만, 상·하 전용 이미지가 있는 건 아니야.
- 공놀이는 RUN/WALK로 이동 → 공 앞에서 SNIFF → WALK로 돌아오기처럼 조합해. 공 이미지는 프론트에서 따로 붙여줘.
- 64px의 정수 배율과 nearest 표시를 기준으로 확인해줘. 그림에 포함된 몸의 들썩임 위에 별도의 점프·바운스를 더하지 않아도 돼.

## 생성과 확인

BASE/IDLE/SIT는 기존 파일 그대로. WALK/RUN/BACK_OFF는 승인된 리그와 서버 하네스 0.3.1 출력이야. 나머지 세 행동은 서버와 같은 PixelLab Animate Pro 요청·프롬프트 및 64×64/바닥 정렬 규칙으로 생성했어. 이번 묶음은 프론트 전달용 파일이며 개발 DB의 강아지 에셋을 교체하지는 않았어.

200개 프레임의 크기·투명 배경·잘림·파일 경로를 검사했어. 동작 전환·충돌·실제 기기에서의 속도는 이 묶음으로 RN 화면에 연결하면서 맞추면 돼.
