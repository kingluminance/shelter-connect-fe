맵 충돌(장애물) 강아지가 막는 영역 플레이어 충돌 강아지 이동 충돌
강아지(발 위치)와 플레이어를 드래그해서 옮기고, 사람의 주황 원은 가운데 마름모(위치)·오른쪽 점(크기)을 끌어 조절하고, 보라(강아지)·분홍(사람) 점선 상자의 왼쪽 위 ✥ 를 끌면 그림 위치, 오른쪽 아래 네모를 끌면 그림 크기가 바뀌고, 빨간 사각형은 위쪽 "대상: 충돌 구역"으로 바꾼 뒤 클릭해서 이동·모서리 드래그로 크기 조절, 표지판·나무 같은 소품은 "대상: 소품" 상태에서 클릭해 이동·크기 조절, Delete로 삭제, 방향키로 1칸씩 이동. 마우스 휠 = 확대/축소, 빈 곳 드래그 = 화면 이동.
